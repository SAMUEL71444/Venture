## Digital.in Backend Setup

Laravel modular-monolith API for the Digital.in UMKM and student platform. Business modules are placeholders; this setup currently includes shared API plumbing, PostgreSQL/Redis development services, and platform settings.

### Requirements

- PHP 8.2+ with `pdo_pgsql`, `pdo_sqlite`, `mbstring`, and `openssl`
- Composer 2+
- Docker Desktop with Docker Compose

### Local setup

From this directory in PowerShell:

```powershell
Copy-Item .env.example .env
composer install
php artisan key:generate
docker compose up -d
php artisan migrate:fresh --seed
php artisan auth:create-admin
php artisan serve
```

`migrate:fresh` menghapus seluruh tabel dan data database yang dipilih. Jalankan hanya pada database development yang boleh di-reset. Seeder mengisi `platform_settings`; daftar universitas belum di-seed sampai daftar kampus disediakan.

Run these in separate terminals for queued and scheduled jobs:

```powershell
php artisan queue:work redis
php artisan schedule:work
```

The API is available at `http://127.0.0.1:8000/api/v1/health`. Configure `CORS_ALLOWED_ORIGINS` for the React frontend origin.

### Tests and formatting

```powershell
composer test
composer lint
composer format
```

Tests use SQLite in memory. PostgreSQL is used for local development through Docker Compose. Money-related logic and business state machines are not implemented in this setup.

### Authentication note

Authentication uses Sanctum bearer access tokens (15 minutes) and rotating opaque refresh tokens (30 days, stored as hashes). Create the first administrator with `php artisan auth:create-admin`; credentials are prompted interactively and are not stored in source control. `JWT_SECRET` remains unused because this project does not use JWT.

## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.
